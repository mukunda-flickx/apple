🍎 Магазин «Яблочко» — VK-бот с акцией «Археология»
https://img.shields.io/badge/license-MIT-blue.svg

«Яблочко» — VK-бот магазина с игровой акцией: пользователи «ведут раскопки» прямо в чате, находят археологические артефакты и с шансом 5% выкапывают промокод на скидку.

📖 О проекте
Обычные магазины выдают промокоды скучно — просто «вот вам код». «Яблочко» превращает это в игру: покупатель отправляет боту команду «копать», получает случайную находку, а иногда — заветный промокод на скидку. Всё происходит в личных сообщениях VK, без сайта и приложения.

Проект создан как наглядный пример для обучения: здесь показано, как организовать VK-бота на vkbottle, реализовать механику «раскопок» с вероятностями, генерировать уникальные промокоды и применять их одноразово. Код написан компактно и читаемо, чтобы его могли разобрать начинающие разработчики.

От аналогов отличается минимализмом: без базы данных и внешних сервисов — состояние хранится в памяти, запуск занимает один файл. Достаточно указать токен сообщества и запустить python bot.py.

🏺 Как работает акция «Археология»
Пользователь пишет боту «копать» — тот «раскапывает» случайную находку.

С вероятностью 5% вместо обычного артефакта попадается промокод вида APPLE-X7Y2Q.

Промокод даёт скидку 10% на заказ.

Каждый промокод можно применить только один раз.

🔑 Настройка
Создайте сообщество VK и включите «Сообщения сообщества».

В разделе «Управление → Работа с API» создайте ключ доступа с правами на сообщения.

Укажите токен одним из способов:

bash
# Linux/macOS
export VK_TOKEN="ваш_токен"

# Windows (cmd)
set VK_TOKEN=ваш_токен
Или впишите токен прямо в bot.py:

python
TOKEN = "ваш_токен"

python bot.py
